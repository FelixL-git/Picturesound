## Picturesound
### About
Hobby project that I work on from time to time.
Target functionality: Generate sounds / music from images. User should be able to test different settings to get different outcomes. Settings could include: How shall the image be sampled over time (horizontal, vertical, diagonal), different parameters on how the current frequencies are defined by the colors of the currently looked at image section, etc. As well as drawing directly in the application and exporting the generated sound file. 

**Used technologies:** C#, .NET, WPF

### Current functionalities
- Drag and drop of image files into the program window

### Releases
No release yet. 
The application is missing too many features for a release at this point. 
However, the code is public and you can create a build yourself if you want.
